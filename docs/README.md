# GHOST rewrite documentation

The rewrite is in discovery. These documents record the initial plan; they do not indicate implemented or approved functionality.

- [SRS](SRS.md): draft business, development and operational requirements, acceptance checks, evidence and open decisions.
- [Milestones](MILESTONES.md): eight-step delivery roadmap, exit criteria, dependencies and issue register.
- [Architecture baseline](ARCHITECTURE-BASELINE.md): current projects, runtime relationships, source gaps and Google integration alternatives.

Start with [SRS review issue #2](https://github.com/williamowen65/ghost-rewrite/issues/2). Architecture discussion remains in [issue #1](https://github.com/williamowen65/ghost-rewrite/issues/1); local development work is tracked in [issue #3](https://github.com/williamowen65/ghost-rewrite/issues/3).

Update documentation and linked issues as decisions are made. Preserve requirement IDs and distinguish draft, approved, implemented and verified states. No technology stack or production migration has been finalized.
